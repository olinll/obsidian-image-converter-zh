### 结论

- 根据上述测试，使用 **WEBP 作为目标格式进行图片压缩可以在保持高图片质量的同时显著减小文件大小**。
- WEBP 通常提供最佳的压缩比，从 JPG 和 PNG 转换时，在所有质量级别（100、50 和 1）下文件大小最小。
- 从 WEBP 转换为其他格式会导致更大的文件大小，说明 WEBP 在压缩图片数据方面更加高效。
- PSNR 值表明压缩图片的质量通常很高，大多数转换在质量 50 时值都在 30 以上。
- 压缩百分比表明，通过以较低质量级别转换为 WEBP 或 JPG，可以实现显著的文件大小缩减。
- 从 PNG 转换为 JPG 或 WEBP（质量 50）可实现超过 90% 的文件大小缩减。
- 在任何质量级别下将 JPG 转换为 PNG 都会导致文件大小增加，说明 PNG 在压缩图片数据方面不如 WEBP 或 JPG 高效。
- 从 PNG 转换为 JPG 或 WEBP（质量 50）的 PSNR 值也相对较高，说明尽管文件大小大幅缩减，压缩图片的质量仍然良好。
