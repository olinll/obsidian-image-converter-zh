# 标注工具

这是一个简单的快速标注/注释工具。当加载完整的 Photoshop 或 Excalidraw 实例对于如此简单的任务来说过于繁重时，这个工具非常适合。我想要一个能让我快速在截图/照片上涂鸦的工具，适用于我正在上的所有课程。理想的工作流程是：将图片/截图粘贴到笔记中 → 在 Obsidian 内部打开，不离开上下文/笔记/当前行 → 做一些涂鸦 → 将图片保存回笔记 → 继续上课。全程不离开 Obsidian，不切换窗口，不复制粘贴，不导出到其他应用程序。

- 提供直接在图片上绘制和添加文字的功能。
- 可以在图片内部或外部绘制或添加文字。您可以缩小到几乎无限大的画布尺寸。超出图片边界的任何内容都会保存回原始图片。
- 始终保留透明度。
- 所有更改都是永久性的，并保存回原始图片。
- 保存时会将所有注释扁平化到图片中。

## 修改标注：

- **选择工具**：默认激活。通过快捷键 (B、A、T) 或按钮取消激活工具（画笔、箭头或文字）即可重新激活选择工具。使用选择工具移动或调整元素。
- **编辑文字**：双击任意位置创建新文字元素。双击已有文字元素进行编辑。缩放时文字会自动锐化以确保清晰度。
- **更改颜色**：选择一个元素，然后从色板中选择颜色或使用取色器。取色器允许输入 HEX、HSL 或 RGB 值。系统会自动计算 6 种主色调，并在下方提供 180 度互补的 6 种互补色。

## 删除：

- 选择一个元素，然后按 Backspace 或 Delete 键。
- 删除所有元素：全选 (CMD+A) 所有元素，然后按 Backspace 或 Delete 键。或使用提供的删除按钮。

## 导航：

- **滚轮**：放大和缩小。
- **空格键**：在画布上平移。

### **工具预设：**

工具预设可重复使用，会记住所选工具的大小、不透明度和混合模式。因此可以拥有例如 3 个自定义画笔：小、中、大 — 每个具有不同的颜色、不透明度和混合模式。可以创建自定义高亮笔或标记笔。箭头和文字同理。

- 创建预设：选择要创建预设的工具 → 选择大小/不透明度/混合模式 → 准备好后：按住 Shift 并点击预设编号即可保存

![image](https://github.com/user-attachments/assets/1dc2bcdc-da4a-41d5-af19-118a8978e543)


### **背景：**

可选择 5 种自定义背景之一：透明、白色、黑色、网格、点阵。

## 注意事项：
- 保存的标注会扁平化到图片中，之后无法修改。
- 这不是 Excalidraw 的替代品。
- 目前不支持将图片拖放到图片标注中。
- 目前不支持使用正片叠底或线性混合模式进行高亮标注。
- 图层的前后排列只能手动操作，按创建顺序排列。后续可能会添加方便使用的按钮。
- 箭头工具会自动在笔划方向创建箭头。某些情况下平滑度可能过强，后续可能会进行修改/调整。
- 目前不支持创建自定义形状、矩形、圆形。不过后续可能会为文字元素添加自定义背景，使文字与背景的分离更容易（创建也更快速）。
